# Нужно от заказчика

Пока этих данных нет, на сайте стоят заметные плейсхолдеры «[Нужно от заказчика: …]». Всё вписывается в `private/config.php` — переделывать код не нужно.

## До запуска сайта

| Что | Где используется | Куда вписать |
|---|---|---|
| Домен на Reg.ru | ссылки, sitemap, превью для мессенджеров, вебхук бота | `site_url` |
| Полное наименование ТСЖ по уставу | подвал, политика | `company.full_name` |
| Юридический адрес | подвал, политика | `company.address` |
| Телефон аварийной службы 24/7 | первый экран заявки, блок «Авария», вопросы, подвал | `company.phone_emergency` |
| Телефон правления | подвал, политика | `company.phone_office` |
| E-mail для обращений и запросов по ПДн | вопросы, подвал, политика | `company.email` |
| Ответственный за обработку ПДн | политика | `company.dpo_name` |
| Номер в реестре операторов ПДн (Роскомнадзор) | политика | `company.rkn_number` |
| Перечень платных и бесплатных услуг, цены, сроки | блок «Услуги и цены» | `prices.*`, затем `services_confirmed => true` |

## Юридическая проверка

- Текст политики обработки ПДн (`/politika/`) — черновик по структуре 152-ФЗ. Нужна проверка юристом.
- Заключение о трансграничной передаче: сообщения через Telegram проходят через зарубежные серверы. Возможно, нужно уведомление Роскомнадзора.
- Уведомление Роскомнадзора об обработке ПДн — если ещё не подано.
